# Your profile lives here

1. Put your CV in this folder (`.pdf`, `.docx`, `.md` or `.txt`).
2. Open the repo in Claude Code and run `/setup`. It reads the CV, asks a few questions and writes `profile.toml`.

Or copy `profile.example.toml` to `profile.toml` and edit it by hand.

Everything in this folder except this README and the example is git-ignored, so your CV and profile stay on your machine even if you push your fork.
